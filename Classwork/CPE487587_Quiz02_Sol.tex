\item What is the difference between parameters and buffers in the realm of PyTorch  \texttt{nn.Module}?

\begin{tcolorbox}[colback=white, colframe=headerRed!75!black]
\vspace{1.5em}
Parameters and buffers are both Tensors and member variable of Neural Network class  \texttt{nn.Module}. However parameters are learable tensors and requires gradient to be true by default, i.e. \texttt{requires\_grad=True}. That is not true for buffers. However, buffers are variables that do store some important information (for example, scaling parameters) that you would need to reload when you when load a trained model for making an inference. Hence, in such a case you need to register both: parameters and buffers in class definition. But buffer neglects operations to compute gradients and update its values. Only parameters are involved in gradient computations.

\vspace{0.5em}
\end{tcolorbox}


\item What happens if you don't register a member variable tensor as parameters in PyTorch \texttt{nn.Module}?

\begin{tcolorbox}[colback=white, colframe=headerRed!75!black]
\vspace{1.5em}

If we do not register a member variable tensor as parameters in PyTorch \texttt{nn.Module} it doesn't become learnable and won't be updated via backpropagation when training of the model is done.

\vspace{0.5em}
\end{tcolorbox}
