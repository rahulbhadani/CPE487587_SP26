 \begin{column}{0.49\textwidth}

\footnotesize

An \textbf{autoencoder} is  a neural network, whose main job is to encode the input into a compressed  representation, and then decode it back such that the reconstructed input is similar as possible to the original one.

It has three parts:
\begin{enumerate}
\item Encoder: Learns the most relevant features and transfers data into a latent space.
\item Latent representation: a middle layer that represents feature in some low dimensional space.
\item Decoder: it takes the reduced features from latent space and lift to the original dimension.
\end{enumerate}
As it turns out, AutoEncoder is a neural network with a bottleneck. 

\end{column}

\begin{frame}{Denoising Autoencoder}




 \begin{columns}[T]
 
  \begin{column}{0.49\textwidth}

\footnotesize

An AutoEncoder can end up learning an identity function (also called null function) where input=output.

To remedy, we add some noise to the input to corrupt it before feeding to AutoEncoder. Such an AE is called denoising AutoEncoder (DAE).

There are two ways to add noise to DAE:

\begin{enumerate}
\item Add Gaussian noise to the input.
\item Randomly set some input nodes to zero.
\item Masking out a certain percentage of the input’s pixels in the case of image data.
\end{enumerate}

\begin{frame}{Stacked Autoencoders}
    \begin{tcolorbox}[colback=boxblue, colframe=deepblue, title=~]
        The stacked autoencoder is a \textit{hack} to obtain a deep model by training only shallow ones in a \textbf{layer-wise, greedy fashion}.
    \end{tcolorbox}

    \vspace{0.3cm}
    \begin{itemize}
        \item \textbf{Phase 1:} Train the outermost encoder and decoder as a single shallow AE.
        \item \textbf{Phase 2:} Encode the dataset; use the result to train the next inner shallow AE.
        \item \textbf{Phase 3:} Repeat until reaching the innermost layers.
        \item \textbf{Result:} Stack the pre-trained layers into one deep architecture.
    \end{itemize}
\end{frame}

\begin{frame}{Motivation}

\footnotesize

    \begin{itemize}
        \item[] We are interested in \textbf{posterior distribution calculation}.
    \end{itemize}

    \begin{tcolorbox}[colback=white, colframe=MainBlue!10, title=\small Recall: Bayesian Framework, fonttitle=\bfseries, coltitle=MainBlue]
        Given the parameter $\theta$ for a data distribution, we have prior as $p(\theta)$, a likelihood, if we write dataset as $\mathcal{D}$, then the posterior distribution can be calculated as:
        
        \begin{equation*}
            \Large p(\theta | \mathcal{D}) = \frac{p(\mathcal{D} | \theta)p(\theta)}{p(\mathcal{D})}
        \end{equation*}
        
        with $p(\mathcal{D}) = \int p(\mathcal{D} |\theta)p(\theta)d\theta$ as the \textit{marginal distribution}.
    \end{tcolorbox}

$\theta$ denotes latent parameters that we want to infer.

\begin{frame}{Variational Objective}


\footnotesize

    \begin{itemize}
        \item[] We turn VI into an optimization problem: we choose a family of tractable distributions $\mathcal{Q}$ and find a member $q(\theta) \in \mathcal{Q}$ that is as close to $p(\theta|\mathcal{D})$ as possible.
    \end{itemize}

    \begin{tcolorbox}[colback=gray!5, colframe=gray!30, boxrule=0.5pt, size=small]
        \centering \small What's the criteria for measuring the closeness between two distributions?
    \end{tcolorbox}

    \pause
    \begin{columns}
        \begin{column}{0.45\textwidth}
            \textbf{KL-Divergence, JS-divergence, etc.}
        \end{column}
        \begin{column}{0.5\textwidth}
             \textit{Goal: Minimize KL divergence from $q(\theta)$ to $p(\theta|\mathcal{D})$}
        \end{column}
    \end{columns}
    
\end{frame}

\begin{frame}[allowframebreaks]{KL Divergence}

\begin{definition}

\begin{align*}
KL( q(\theta) || p(\theta | \Dcal) ) = \bigint q(\theta) \log \frac{q(\theta)}{p(\theta | \Dcal)} d\theta
\end{align*}

\end{definition}





But KL divergence still depends on $p(\Dcal) = \int p(\Dcal | \theta) p(\theta)\theta$.

To see, how, we can rewrite the KL integral using the definition of Expectation.

\begin{tcolorbox}[
    enhanced,                          % Enables advanced skin features
    colback=gray!5!white,              % Light gray background
    colframe=teal!75!black,            % Dark teal frame
    boxrule=0.5pt,                     % Thin outer border
    left=4mm,                          % Extra space for the accent bar
    enlarge left by=0.1mm,               % Slight offset from margin
    sharp corners,                     % Professional, clean edges
    borderline west={3pt}{0pt}{teal},  % The "Steel" accent bar
    drop lifted shadow=black!30!white, % Subtle "lifted" shadow for depth
    fonttitle=\bfseries\sffamily,      % Bold, clean title font
    coltitle=white,                    % White text on teal background
    attach boxed title to top left={   % The "Ribbon" effect
        xshift=0.1mm, 
        yshift=-0.1mm, 
        yshifttext=-0.1mm 
    },
    boxed title style={
        colback=teal!75!black, 
        sharp corners, 
        boxrule=0pt
    },
    title={}    % Your title here
]

\begin{align*}
\text{KL}(q(\theta)  || p(\theta|\Dcal))  & = \Ebb_q \bigg[ \log \frac{q(\theta)}{p(\theta | \Dcal)} \bigg]\\
& = \Ebb_q [ \log q(\theta) ]  - \Ebb_q [ \log p(\theta | \Dcal)\\
& = \Ebb_q [ \log q(\theta) ]  - \Ebb_q \bigg[ \log \frac{p(\theta , \Dcal)}{p(\Dcal)}\bigg]\\
& = \Ebb_q [ \log q(\theta) ]  - \Ebb_q[\log p(\theta, \Dcal) ]  + \Ebb_q[ \log p(\Dcal) ] \\
& = \Ebb_q [ \log q(\theta) ]  - \Ebb_q[\log p(\theta, \Dcal) ]  + \int q(\theta) \log p(\Dcal) d \theta\\
& = \Ebb_q [ \log q(\theta) ]  - \Ebb_q[\log p(\theta, \Dcal) ]  + \log p(\Dcal) 
\end{align*}
\end{tcolorbox}
The last step is because $\log p(\Dcal)$ is a constant with respect to $q(\theta)$. 

\vspace{10pt}

We can ignore $\log p(\Dcal)$ in our optimization problem.

\vspace{10pt}

Minimizing a quantity means maximizing its negative, and so we maximize the following quantity:

\begin{align*}
\text{ELBO}(q) & = -( \text{KL}(q(\theta)  || p(\theta|\Dcal))  - \log p(\Dcal) ) \\
& = - \bigg( \Ebb_q [ \log q(\theta) ]  - \Ebb_q[\log p(\theta, \Dcal) ]  + \log p(\Dcal)  - \log p(\Dcal) \bigg)\\
& =  \Ebb_q[\log p(\theta, \Dcal) ] - \Ebb_q [ \log q(\theta) ]
\end{align*}

We could expand joint probability and rewrite

\begin{align*}
\text{ELBO}(q) & = \Ebb_q[ \log p(\Dcal | \theta)] + \Ebb_q[ \log p(\theta)] - \Ebb_q [ \log q(\theta) ]\\
& = \Ebb_q[ \log p(\Dcal | \theta)] + \Ebb_q \bigg[ \log \frac{p(\theta)}{q(\theta)} \bigg]\\
& = \Ebb_q[ \log p(\Dcal | \theta)] - \Ebb_q \bigg[ \log \frac{q(\theta)}{p(\theta)} \bigg]\\
& = \Ebb_q[ \log p(\Dcal | \theta)] - \text{KL}( q(\theta) || p(\theta))
\end{align*}



We could also note that 
\begin{align*}
p(\Dcal, \theta) = p(\Dcal)p(\theta, \Dcal) \text{ from the  Bayes' rule.}
\end{align*}
Hence, 
\begin{align*}
\text{ELBO}(q) & = \Ebb_q[\log p(\theta| \Dcal) + \log p(\Dcal) ] - \Ebb_q [ \log q(\theta) ] \\
& {\text{\color{decoderPurple} Taking constant out of the expectation, and distributing the expectation}}\\
\text{ELBO}(q) & = \Ebb_q[\log p(\theta| \Dcal) ] - \Ebb_q [ \log q(\theta) ] +  \log p(\Dcal)\\
& \text{Since } \Dcal \text{ is fixed } , \log p(\Dcal) \text{ is a constant with respect to } q\\
  \text{ELBO}(q) & = \Ebb_q[\log p(\theta| \Dcal) ] - \Ebb_q [ \log q(\theta) ] + constant
\end{align*}
\end{frame}

\begin{frame}{Variational Objective: The ELBO}


The \textbf{Evidence Lower Bound (ELBO)} is defined as:
    
    \begin{tcolorbox}[highlight style]
        \centering
        $\text{ELBO}(q) = \mathbb{E}_q[ \log p(\mathcal{D}|\theta)] - \text{KL}(q(\theta) \parallel p(\theta))$
    \end{tcolorbox}

because the marginal is called \textit{evidence} as well.    
    
    
    \begin{small}
   A $\log p (\Dcal)$ is constant wrt $q$, hence minimizing $KL(q(\theta)  || p(\theta|\Dcal)) $ is equivalent to maximizing ELBO. ELBO consists of two terms:
    \begin{itemize}
        \item[\textcolor{DeepBlue}{\tiny $\blacksquare$}] \textbf{Expected log-likelihood:} Encourages $q$ to place mass on parameters that explain the data well.
        \item[\textcolor{DeepBlue}{\tiny $\blacksquare$}] \textbf{Negative KL to prior:} Encourages $q$ to be close to the prior (regularizer).
    \end{itemize}
    \end{small}

    \vspace{0.1cm}
    \centering \footnotesize \color{DeepBlue} \textit{VI maximizes a lower bound on the log marginal likelihood.}

\end{frame}

\begin{frame}{What is Variational in VI?}
    
    \begin{tcolorbox}[title=]
We are not looking to find a single best value that maximizes the log likelihood, but rather a single best function. 
    \end{tcolorbox}

    \vspace{0.5cm}

    \begin{columns}[T]
        \begin{column}{0.5\textwidth}
            \textbf{Moving Beyond MLE}
            \begin{itemize}
                \item We are \textbf{not} looking to find a single best value that maximizes the log-likelihood.
                \item Instead, we seek to identify the single \textbf{best function} (distribution).
            \end{itemize}
        \end{column}
        
        \vrule{}
        
        \begin{column}{0.45\textwidth}
            \textbf{The Methodology}
            \begin{itemize}

                \item The term "Variational" is derived directly from this mathematical framework.
            \end{itemize}
        \end{column}
    \end{columns}

    \vspace{0.8cm}
    
    \begin{center}
        \footnotesize
        \textit{Goal: Approximate a complex posterior by finding the closest member of a simpler family of distributions.}
    \end{center}

\begin{frame}{The Euler-Lagrange Equation}

The main tool in variational calculus is the Euler-Lagrange equation

    \begin{tcolorbox}[vcAccent, title={\faCalculator\enspace Basic Calculus}]
    \color{vcSilver}
    \Large
\begin{align*}
\frac{d}{dx}\pdv{F}{y'} - \pdv{F}{y} = 0
\end{align*}
\end{tcolorbox}
which tells us the condition a function $y(x)$ mut satisfy to  minimize/maximize a given functional. In robotics, $y(x)$ could be robot's trajectory. $F$ could be energy, cost, control effort, distance, etc.

\end{frame}

\begin{frame}{Mean-field Variational Family}

\footnotesize

The next question, how do we choose {\color{red}$Q$}.  A common choice for the variational family $Q$ is the \textbf{mean-field family}. Other options are \textit{full-covariance Gaussians}, and \textit{Normalizing Flows}.

\begin{tcolorbox}[highlight style]
The mean-field variational family assumes that the latent variables are independent of each other in the approximate posterior. Mathematically, if we have parameters $\theta = (\theta_1, \theta_2, \ldots, \theta_M)$, the mean-field approximation factorizes as:


\begin{align*}
q(\theta ) = \prod_{j=1}^M q_j(\theta_j)
\end{align*}

\end{tcolorbox}

\scriptsize

 \begin{tcolorbox}[colback=white, colframe=MainBlue!10, title=~, fonttitle=\bfseries, coltitle=MainBlue]
Each $q_j$ is a marginal variational distribution for the $j$-th parameter or group of parameters. The key point is that there are no cross-terms or dependencies between different $\theta_j$'s in the approximation.
\end{tcolorbox}


\begin{tcolorbox}[blanker, borderline west={2pt}{0pt}{gray!40}, left=10pt]
\tiny
The term "mean-field" comes from physics, specifically from statistical mechanics. In physics, mean-field theory approximates a many-body problem by replacing interactions with an average or "mean" field. Similarly, in variational inference, we're approximating a complex posterior where variables are dependent by a simpler distribution where they're independent.
\end{tcolorbox}



\end{frame}

\begin{frame}[allowframebreaks]{Mean-field Variational Inference with ELBO}

\begin{tcolorbox}[title=Recall: The ELBO Definition, colframe=theoryBlue]
\footnotesize
 \begin{align*}
 \text{ELBO}(q) & = \Ebb_q[ \log p(\theta, \Dcal)] - \Ebb_q[\log q(\theta) ]\\
 & = \int \prod_{i=j}^M q_j(\theta_j) \log p(\theta, \Dcal) d\theta - \int \prod_{i=j}^M q_j(\theta_j)
 \end{align*}
\end{tcolorbox}

\vspace{0.2cm}

\small
 We optimize ELBO with respect to a single variational density $q_j(\theta_i)$ and keep others fixed.

\begin{tcolorbox}[colback=gray!5, colframe=gray!50, title=Derivation for $q_j$]
\scriptsize
 \begin{align*}
 \text{ELBO}(q_j) & = \int \prod_{i=j}^M q_j(\theta_j) \log p(\theta, \Dcal) d\theta - \int \prod_{i=j}^M q_j(\theta_j) \log \prod_{i=j}^M q_j(\theta_j) d\theta \\
 & = \int \prod_{i=j}^M q_j(\theta_j) \log p(\theta, \Dcal) d\theta  - \int  q_j(\theta_j) \log q_j(\theta_j) d\theta_j  - \underbrace{\int \prod_{i\neq j}^M q_j(\theta_j) \log \prod_{i\neq j}^M q_j(\theta_j) d\theta_{-j}}_{\color{blue}\text{Fixed with respect to }q_j{\theta_j}}\\
 & \propto \int \prod_{i=j}^M q_j(\theta_j) \log p(\theta, \Dcal) d\theta  - \int  q_j(\theta_j) \log q_j(\theta_j) d\theta_j \\
 & = \int q_j(\theta_j) \bigg( \int \prod_{i\neq j}^M q_j(\theta_j) \log p(\theta, \Dcal) d\theta_{-j}  \bigg)d\theta_j - \int  q_j(\theta_j) \log q_j(\theta_j) d\theta_j\\
 & = q_j(\theta_j) \Ebb_{q(\theta_{-j})}[ \log p(\theta, \Dcal)] d\theta_j - \int q_j(\theta_j) \log q_j(\theta_j) d\theta_j
 \end{align*}
\end{tcolorbox}

\small

We could use variational calculus to find the optimal variational density $q^*_j (\theta_j)$.
 
 We can further define $\log \tilde{p} (\Dcal, \theta_j) =  \Ebb_{q(\theta_{-j})}[ \log p(\theta, \Dcal)] d\theta_j + Constant$.
 
The constant is from the previous step just before the proportional.
 
 Hence, 
 
 
\begin{tcolorbox}[colframe=uiRose, title=Relation to KL Divergence]
\tiny
 \begin{align*}
  \text{ELBO}(q_j) & \propto \int  q_j(\theta_j) \log \tilde{p} (\Dcal, \theta_j)d\theta_j   - \int q_j(\theta_j) \log q_j(\theta_j) d\theta_j \\
 & \text{\color{uiRose} Merge the integral due to common integraion variable}\\
& =   \int  q_j(\theta_j) \log\cfrac{\tilde{p} (\Dcal, \theta_j)}{q_j(\theta_j)}d\theta_j \\
& = - \int  q_j(\theta_j) \log\cfrac{q_j(\theta_j)}{\tilde{p} (\Dcal, \theta_j)}d\theta_j\\
& = - KL( q_j(\theta_j)  || \tilde{p} (\Dcal, \theta_j)) \quad \text{\color{rnnNavy}(Using the definition of KL Divergence)} \\
& 
\quad \text{The ELBO is equal to the negative KL divergence up to an additive constant.}
 \end{align*}
\end{tcolorbox}

\footnotesize
Hence, maximizing the ELBO is equivalent to minimizing the KL Divergence between $q_j(\theta_j)$  and $\tilde{p} (\Dcal, \theta_j)$.

Hence, under the mean-field assumption, the optimal variational density is given by 

\begin{tcolorbox}[colframe=proofGreen, title=The Optimal Mean-Field Update]
\begin{align*}
q_j^* & = exp\bigg(\Ebb_{q(\theta_{-j})}[ \log p(\theta, \Dcal)] d\theta_j + Constant \bigg)\\
& = \cfrac{\Ebb_{q(\theta_{-j})}[ \log p(\theta, \Dcal)] d\theta_j)}{\int \Ebb_{q(\theta_{-j})}[ \log p(\theta, \Dcal)] d\theta_j}
\end{align*}
\end{tcolorbox}

Note that this is not an explicit solution because each optimal variational density depends on all others. Hence, the true solution will be iterative ones.

This process is called \textbf{Coordinated Ascent Variational Inference}.

\end{frame}

\begin{frame}{Stochastic Gradients for Variational Inference}

We can use gradient descent based methods for optimizing ELBO.


    \begin{tcolorbox}[colback=softblue, colframe=mainblue, arc=4pt, boxrule=1pt, left=10pt, right=10pt, top=8pt, bottom=8pt]
    
We need to compute gradients of the ELBO wrt to the parameters of $q$.

\begin{align*}
\Lcal (\lambda) = \text{ELBO}(q_\lambda) = \mathbb{E}_{q_{\lambda}(\theta)}[ \log p(\mathcal{D}|\theta)] - \text{KL}(q_{\lambda}(\theta) \parallel p(\theta))
\end{align*}
where $\lambda$ is the variational parameters such  as mean and log-std of a Gaussian.
\end{tcolorbox}

The KL term can often be computed analytically (e.g., when both $q$ and $p$ are Gaussians). The expected log‑likelihood term, however, usually requires approximation.


    \begin{tcolorbox}[highlight style]
In PyTorch, we can use reparameterization trick to estimate the gradients of the expectation.
\end{tcolorbox}

\end{frame}

\begin{frame}[allowframebreaks]{Example: KL Divergence between Two Gaussians}


\footnotesize

\begin{tcolorbox}[colframe=uiRose, title=~~]

Derive the closed-form $KL(q \| p)$ where:
\begin{align*}
    q(z) &= \mathcal{N}(z;\, m,\, s^2)
           = \frac{1}{\sqrt{2\pi s^2}} \exp\!\left(-\frac{(z-m)^2}{2s^2}\right) \\[6pt]
    p(z) &= \mathcal{N}(z;\, \mu_0,\, \sigma_0^2)
           = \frac{1}{\sqrt{2\pi\sigma_0^2}} \exp\!\left(-\frac{(z-\mu_0)^2}{2\sigma_0^2}\right)
\end{align*}
\end{tcolorbox}




\begin{tcolorbox}[title=Solution, colframe=theoryBlue, breakable]

\begin{align*}
    KL(q \| p)
    &= \int_{-\infty}^{\infty} q(z)\, \log \frac{q(z)}{p(z)}\, dz \\
    &= \int_{-\infty}^{\infty} q(z)\, \log q(z)\, dz
       - \int_{-\infty}^{\infty} q(z)\, \log p(z)\, dz
\end{align*}

 \end{tcolorbox}

\pause


\begin{tcolorbox}[colframe=theoryBlue, breakable]

 
Taking the log of $q(z)$:
\begin{align*}
    \log q(z)
    &= \log \left[ \frac{1}{\sqrt{2\pi s^2}}
       \exp\!\left(-\frac{(z-m)^2}{2s^2}\right) \right] \\
    &= -\frac{1}{2}\log(2\pi) - \frac{1}{2}\log(s^2) - \frac{(z-m)^2}{2s^2}
\end{align*}
 
 
 Taking the log of $p(z)$:
\begin{align*}
    \log p(z)
    &= \log \left[ \frac{1}{\sqrt{2\pi\sigma_0^2}}
       \exp\!\left(-\frac{(z-\mu_0)^2}{2\sigma_0^2}\right) \right] \\
    &= -\frac{1}{2}\log(2\pi) - \frac{1}{2}\log(\sigma_0^2) - \frac{(z-\mu_0)^2}{2\sigma_0^2}
\end{align*}

 \end{tcolorbox}

\pause


\begin{tcolorbox}[colframe=theoryBlue, breakable]

Taking the difference:
\begin{align*}
    \log q(z) - \log p(z)
    &= \left[-\frac{1}{2}\log(2\pi) - \frac{1}{2}\log(s^2) - \frac{(z-m)^2}{2s^2}\right] \\
    &\quad - \left[-\frac{1}{2}\log(2\pi) - \frac{1}{2}\log(\sigma_0^2) - \frac{(z-\mu_0)^2}{2\sigma_0^2}\right] \\[6pt]
    &= \frac{1}{2}\log(\sigma_0^2) - \frac{1}{2}\log(s^2)
       - \frac{(z-m)^2}{2s^2} + \frac{(z-\mu_0)^2}{2\sigma_0^2} \\[6pt]
    &= \log\frac{\sigma_0}{s}
       - \frac{(z-m)^2}{2s^2}
       + \frac{(z-\mu_0)^2}{2\sigma_0^2}
\end{align*}

 \end{tcolorbox}

\pause


\begin{tcolorbox}[colframe=theoryBlue, breakable]

\begin{align*}
    KL
    &= \mathbb{E}_q\!\left[\log q(z) - \log p(z)\right] \\
    &= \mathbb{E}_q\!\left[
         \log\frac{\sigma_0}{s}
         - \frac{(z-m)^2}{2s^2}
         + \frac{(z-\mu_0)^2}{2\sigma_0^2}
       \right] \\[6pt]
    &= \log\frac{\sigma_0}{s}
       - \frac{1}{2s^2}\,\mathbb{E}_q\!\left[(z-m)^2\right]
       + \frac{1}{2\sigma_0^2}\,\mathbb{E}_q\!\left[(z-\mu_0)^2\right]
\end{align*}
 
 
  \end{tcolorbox}

\pause


\begin{tcolorbox}[colframe=theoryBlue, breakable]
 
 This is the variance of $q$:
\begin{align*}
    \mathbb{E}_q\!\left[(z - m)^2\right] &= s^2
\end{align*}
 
 
 Add and subtract $m$ inside the square:
\begin{align*}
    \mathbb{E}_q\!\left[(z - \mu_0)^2\right]
    &= \mathbb{E}_q\!\left[(z - m + m - \mu_0)^2\right] \\
    &= \mathbb{E}_q\!\left[(z-m)^2\right]
       + 2(m-\mu_0)\,\mathbb{E}_q\!\left[z - m\right]
       + (m - \mu_0)^2 \\
    &= s^2 + 2(m - \mu_0) \cdot 0 + (m - \mu_0)^2 \\
    &= s^2 + (m - \mu_0)^2
\end{align*}
 
where $\mathbb{E}_q[z - m] = 0$ since $m$ is the mean of $q$.
 
  \end{tcolorbox}

\pause


\begin{tcolorbox}[colframe=theoryBlue, breakable]

 \begin{align*}
    KL
    &= \log\frac{\sigma_0}{s}
       - \frac{1}{2s^2} \cdot s^2
       + \frac{1}{2\sigma_0^2}\left[s^2 + (m - \mu_0)^2\right] \\[6pt]
    &= \log\frac{\sigma_0}{s}
       - \frac{1}{2}
       + \frac{s^2 + (m - \mu_0)^2}{2\sigma_0^2} \\[10pt]
    & = \log\frac{\sigma_0}{s}
            + \frac{s^2 + (m - \mu_0)^2}{2\sigma_0^2}
            - \frac{1}{2}
\end{align*}
 
  \end{tcolorbox}

\pause


\begin{tcolorbox}[colframe=theoryBlue, breakable]

 Substituting $\mu_0 = 0$ and $\sigma_0 = 1$:
\begin{align*}
    KL
    &= \log\frac{1}{s} + \frac{s^2 + m^2}{2 \cdot 1} - \frac{1}{2} \\[6pt]
    &= -\log s + \frac{s^2 + m^2}{2} - \frac{1}{2}
\end{align*}
 

\end{tcolorbox}



\end{frame}

\begin{frame}{Steps in VAE}


\begin{enumerate}
\item Use a neural network $f_\wbf$ parametrized by $\wbf$ to compute the posterior

\item Draw $L$ random $\zbf$ vectors from  the distribution.

\item Using another neural network $g_\vbf$ parameterized by $\vbf$ the Estimate $p_\vbf(\xbf | \zbf)$ .

\item Update $\wbf$ and $\vbf$ using gradient ascent/descent.

\end{enumerate}

\begin{frame}{Objective in VAE}


We want to maximize $\log p_\vbf(\xbf)$, the log-likelihood of our data. But as this is intractable and difficult, we optimize a lower bound instead through ELBO.

    \begin{tcolorbox}[colback=softblue, colframe=mainblue, arc=4pt, boxrule=1pt, left=10pt, right=10pt, top=8pt, bottom=8pt]

\begin{align*}
ELBO(\wbf, \vbf, \xbf) = \Ebb_{q_\wbf(\zbf|\xbf)}[ \log p_\vbf (\xbf | \zbf)] -  KL( q_\wbf(\zbf|\xbf) || p(\zbf) )
\end{align*}
 which needs to be maxmized.   
    \end{tcolorbox}

\end{frame}

\begin{frame}{The Reparameterization Trick in VAE}

\footnotesize


\begin{flowbox}

To train VAE, we need gradients to flow back through the sampling operation. However, the sampling operation $z \sim q_\wbf(\zbf | \xbf)$ is not differentiable, as the randomness blocks the gradient. The flow of the information is disconnected due to randomness.
\end{flowbox}

\vspace{3pt}

\begin{columns}

\pause 

\column{0.48\linewidth}

Hence, we have a reparameterization trick
\begin{reparambox}
Reparameterize the sample: separate the random part from the learned parameters:
\begin{align*}
\zbf = \bm\mu + \bm\sigma \odot \varepsilon, \quad \varepsilon \sim \Ncal (0, \Ibf)
\end{align*}
\end{reparambox}

\pause

Now, $\varepsilon$ is a fixed random variable drawn from a standard normal distribution and the network parameters $\mu$ and $\sigma$ are deterministic functions of $\xbf$, so gradients can flow through them, thus, 
\begin{align*}
q_\wbf(\zbf | \xbf) = \Ncal (\zbf ; \bm\mu(\xbf), diag(\bm\sigma^2(\xbf)))
\end{align*}

\pause 
\column{0.48\linewidth}




For numerical stability, we output $\log \bm\sigma^2$ which can be any real number, $\bm\sigma > 0$ would require constraint. 

\pause 
\vspace{5pt}

\scriptsize


 \begin{tcolorbox}[colback=softblue, colframe=mainblue, arc=4pt, boxrule=1pt, left=10pt, right=10pt, top=8pt, bottom=8pt]
For this to work, each dimension of $\zbf$ is assumed \textbf{independent} making the covariance matrix diagonal. The encoder learns the mean and standard deviation (uncertainty) of each latent dimension.
\end{tcolorbox}

 \end{columns}




\end{frame}

\begin{frame}{Decoder in VAE}

\footnotesize

\begin{reparambox}
\begin{align*}

\end{align*}
\end{reparambox}

\vspace{10pt}

We can place the prior as $p(\zbf) = \Ncal(0, \Ibf)$,  that encourages the encoder to keep the latent representation centered and structured, enabling random generation: sample $\zbf \sim p(\zbf)$ and decode.

\begin{frame}{Reconstruction Loss in VAE Objective}
In ELBO, we could rewrite reconstruction loss

\begin{align*}
\Ebb[ \log p_\vbf (\xbf| \zbf) ] \approx -\frac{1}{2} || \xbf - \hat{\xbf}||^2
\end{align*}

And interestingly, KL Divergence for two Gaussians have a closed form solution:

\begin{align*}
KL  = -\frac{1}{2} \sum_{j=1}^d  ( 1  + \log \sigma_j^2 - \mu_j^2 - \sigma_j^2)
\end{align*}


\end{frame}

\begin{frame}{Latent Space in VAE}

On a trained VAE, after the convergence, the latent space has a desirable properties:

\begin{itemize}
\item Continuity, with which nearby points in latent space decode to similar outputs;
\item Completeness, where any sampled $\zbf \sim \Ncal(0, \Ibf)$ decodes to some plausible data thereby giving you a realistic looking synthetic data;
\item Interpolation, where interpolating between two codes is semantically smooth;
\end{itemize}

    \begin{tcolorbox}[colback=white, colframe=MainBlue!10, title=~, fonttitle=\bfseries, coltitle=MainBlue]
    
    A well trained VAE organizes its latent space in such a way that similar looking concepts cluster together.
    
    \end{tcolorbox}

\end{frame}

\begin{frame}{A Note on Isotropic Gaussian in VAE}

A Gaussain $\Ncal(\bm\mu, \bm\Sigma)$ is isotropic when $\Sigma = \sigma^2 \Ibf$,  its probability contours are perfect hyperspheres, not eillipsoid.

\begin{columns}

\column{0.49\linewidth}

    \begin{tcolorbox}[enhanced, borderline west={2pt}{0pt}{red!70!black}, colback=red!5, frame hidden, sharp corners]
    
    Prior uses $p(\zbf) = \Ncal(0, \Ibf)$ which is full isotropic.
  
    \end{tcolorbox}


\column{0.49\linewidth}

    \begin{tcolorbox}[enhanced, borderline east={2pt}{0pt}{WGANBlue!70!black}, colback=WGANBlue!5, frame hidden, sharp corners]
    
    Posterior is modeled using $q_\wbf(\zbf|\xbf) = \Ncal(\bm\mu, diag(\bm\sigma^2))$ which is a diagonal Gaussian.
  
    \end{tcolorbox}
    
\end{columns}

\begin{itemize}
\item  The diagonal covariance means each dimension is independent, so the joint KL factors into a sum of per-dimension KLs. Each term has an exact formula, as seen earlier.

\item With Isotropic Gaussain, drawing random $\varepsilon \sim \Ncal(0, \Ibf)$ is just $d$ independent standard normals.
\end{itemize}

\end{frame}
